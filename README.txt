《19:04》离线网页叙事游戏

启动：双击 index.html，推荐使用 Chromium/Chrome/Edge。
如浏览器限制 file:// 下 PDF 锚点，可使用任意本地静态服务器打开；主线链接本身不依赖服务器。

作品规则：
- 全程为静态网页与文件阅读
- 图片全部为叙事配图，关闭图片仍可完整通关
- PDF 关键内容有可选择文本层
- 进度只保存在浏览器 localStorage
- 顶部“历史记录 / 整理一下”属于非叙事辅助层

建议主线顺序不是强制关卡：2026 专题 → 学校/个人空间 → 招生须知 → 二手信息/调班 → 驾驶员论坛 → 晚班交接 → 站台与通道文件 → 附页17 → 完整口述 → 结页。
